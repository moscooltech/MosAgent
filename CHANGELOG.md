# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] - 2026-08-21

### Added
- Initial release
- AI provider abstraction (OpenAI, Gemini, OpenRouter, Groq, custom)
- Natural language command input
- Android Accessibility Service integration
- Agent engine with observe→reason→act→verify loop
- Tool registry with 17+ tools
- Facebook post generation and preparation
- Social media content templates
- Three automation modes (Safe, Assisted, Autonomous)
- Task state machine
- Conversational memory
- Task history with Room database
- Secure API key storage (Android Keystore)
- Material 3 UI with dark theme
- Home screen with command input
- Agent timeline screen
- Post preview with edit and regenerate
- Settings screen
- First-run onboarding flow
- Emergency STOP button
- GitHub Actions CI/CD
- Release automation with GitHub Releases
- Unit tests
- ProGuard/R8 rules
- MIT License
- README, CONTRIBUTING, SECURITY, CHANGELOG documentation
